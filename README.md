![Version](https://img.shields.io/badge/version-0.8.5--beta-blueviolet.svg)
![Platform](https://img.shields.io/badge/platform-Windows%207%2F8%2F10%2F11-success.svg)
![Framework](https://img.shields.io/badge/.NET%20Framework-4.7.1-informational.svg)
![License](https://img.shields.io/badge/license-MIT-purple.svg)

> **Интерактивный 2D аниме чиби-маскот для рабочего стола Windows с Shimeji-физикой, лазанием по окнам, динамическим трекингом глаз, системой кормления и встроенным автообновлением через GitHub Releases!**

---

## ✨ О персонаже

- **Причёска**: Пышные многослойные фиолетовые волосы с верхним ахогэ (завитком на макушке), объёмным хохолком, двумя красными заколками-рожками и длинными прядями с мягким оливково-зелёным градиентом.
- **Глаза**: Большие выразительные изумрудно-оливковые аниме-глаза с четырёхконечными золотыми звёздами-бликами в зрачках, естественным морганием и плавным 2D слежением за курсором мыши.
- **Гардероб**: Уютный вязаный полосатый свитер «оверсайз» (фиолетовый с белым) с длинными рукавами-«лапками», золотой кулон-звёздочка, чёрная плиссированная юбочка, свободные приспущенные гольфы и туфельки.

---

## 🎮 Возможности и Интерактивность

### 🧗 1. Физика Shimeji и взаимодействие с окнами
- **Лазание по боковым граням окон**: при поднесении к активному окну персонаж цепляется за его рамку лапками и ножками и карабкается вверх с покадровой анимацией.
- **Сидение на заголовке окна (Ledge Sitting)**: добравшись до верха окна, чиби-тян садится на заголовок, свешивает ножки в гольфах и отдыхает.
- **Мягкая гравитация**: если окно свернуть или закрыть, персонаж мягко спрыгивает и приземляется на панель задач Windows.

### 👀 2. Динамический 2D трекинг взгляда
- Зрачки плавно следуют за движениями вашего курсора мыши в реальном времени.
- Встроенные веки и реснички маскируют зрачки, сохраняя естественную анатомию глаз.
- Автоматически скрывается при моргании, сидении и лазании, предотвращая графические артефакты.

### 🍰 3. Интерактивное кормление (Вкусняшки)
- Через контекстное меню (ПКМ ➔ **🍰 Угостить вкусняшкой**) можно угостить её:
  - 🍰 **Клубничным тортиком**
  - 🧋 **Таро Бабл-ти**
  - 🍓 **Свежей клубничкой**
  - 🍪 **Звёздным печеньем**
- Лакомство падает рядом, персонаж поворачивается к нему, радостно кушает с забавными звуками и эффектами сердечек!

### 💬 4. Диалоговый чат
- **Двойной клик** по персонажу (или ПКМ ➔ **💬 Поговорить**) открывает окно ввода.
- Напишите ей что угодно: она реагирует на приветствия, вопросы о настроении, играх, коде и учёбе.

### 🌸 5. Шкала привязанности и поглаживания (Headpats)
- Проведите курсором по волосам на голове — чибик пружинит, смущается, издаёт милые звуки («Няяя~», «Мур-мур~») и разбрасывает звёздочки.
- Забота повышает уровень дружбы от «Стесняшки» до «Родственной души».

### 🎵 6. Реакции на открытые программы
- **Игры** (Steam, Genshin, Minecraft и др.) ➔ садится играть в портативную фиолетовую консоль.
- **Творчество и Код** (VS Code, Visual Studio, Photoshop и др.) ➔ садится рисовать на графическом планшете.
- **Музыка и Видео** (Spotify, YouTube, AIMP, Discord и др.) ➔ подпевает и спавнит нотки.
- **Ночное время** (после 23:00) ➔ засыпает в обнимку со звёздной плюшевой подушкой.

## 🛠 Локальная Сборка из исходников

Для сборки не требуется Visual Studio или сторонние пакеты — достаточно встроенного компилятора Windows:

```cmd
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:exe /out:"desktop-pet\DesktopPet.exe" /lib:"C:\Program Files (x86)\Reference Assemblies\Microsoft\Framework\.NETFramework\v4.7.1" /reference:"System.dll","System.Core.dll","System.Drawing.dll","WindowsBase.dll","PresentationCore.dll","PresentationFramework.dll","System.Xaml.dll","System.IO.Compression.dll","System.IO.Compression.FileSystem.dll" "desktop-pet\src\DesktopPet.cs"
```

Или просто запустите:
```cmd
package_release.bat
```

```
├── Запустить_Питомца.bat      # Лаунчер для пользователей
├── .gitignore                 # Игнорирование временных и билд-файлов
└── README.md                  # Документация проекта
```
